目录

主界面

顶部工具栏

  • 导入 CSV：导入资产文件，生成资产条目和来源记录。
  • 同步状态徽标：显示当前同步状态，例如成功、失败、待同步。
  • 帮助按钮：打开这份 HTML 说明页。

底部页签

  • 资产列表：查看资产、改状态、删除、批量操作。
  • 资产管理：看来源文件、做 iCloud / 飞书 / Reminder 操作。
  • 历史记录：查看每次状态变化并管理记录。

资产列表

搜索 一键全部出库 批量状态 删除设备
  • 搜索框：支持按外编号、名称、型号、品牌搜索。
  • 添加：手动新增一个资产。
  • 一键全部出库：把当前在库资产统一变成已出库，并填写同一批的操作信息。
  • 批量状态：对选中资产执行批量入库、批量出库、批量送修、批量待报废。
  • 删除：删除选中的设备条目，并清理对应历史记录与来源关联。
  • 右键资产：可直接执行归还、送修、待报废、出库、查看详情、删除设备。
  • 双击资产：进入资产详情页。

资产详情

状态区

  • 显示当前资产状态、条码和最近更新时间。
  • 不同状态会使用不同颜色高亮，方便肉眼快速判断。

动作按钮

  • 归还：把资产改回在库，并生成入库记录。
  • 出库：填写操作人、备注、预计归还时间，生成出库记录。
  • 送修：改成送修状态，并生成送修记录。
  • 待报废：改成待报废状态，并生成待报废记录。

详情页右上角还有 删除设备 按钮，用于直接移除当前资产。

历史记录

  • 搜索框：按条码、名称、操作人过滤历史。
  • 全选 / 删除选中：用于批量清理记录。
  • 同步选中：把带预计归还时间的出库记录同步到 Reminder。
  • 同步 Reminder：批量同步所有符合条件的出库记录。
  • 清空历史：删除所有历史记录。
  • 右键记录：可编辑或删除单条记录。

右键编辑能改什么

  • 操作人
  • 备注
  • 预计归还时间（仅出库记录）

资产管理

统计卡片

  • 显示总资产数量。
  • 显示当前出库数量。
  • 显示来源文件数量。

来源文件列表

  • 显示每次导入的文件名、时间和资产数量。
  • 双击来源可看该文件关联资产。
  • 更新 CSV：用新的 CSV 更新当前来源，优先按外编码对比。
  • 命中的旧条目会保留当前出入库 / 送修 / 待报废状态。
  • 新条目会直接增加到当前来源里。
  • 消失条目会先显示名称、外编码、当前状态，再确认是否批量删除。
  • 编辑来源名称：支持手动修改来源显示名称。
  • 删除来源记录前会确认，同时清理对应资产。

同步与配置

iCloud 同步

  • 选择目录：设置同步目录。
  • 从同步目录导入：把目录里的数据拉回本地。
  • 导出到同步目录：把当前本地数据写出去。
  • 双向同步：在本地和目录之间做一次合并同步。

飞书同步

  • 填写 App ID、App Secret。
  • 支持直接解析资产表和记录表链接。
  • 保存配置 后会自动触发一次飞书同步。
  • 本地状态变化会继续自动回写飞书。
  • 支持 全量同步、从飞书导入、双向同步。
  • 全量同步会先做比对，不是只往后追加。
  • 资产表按 外编号 对齐：有则更新，没有则新增，本地已删除的远端旧条目会清理。
  • 操作记录表优先按 记录ID 对齐，没有时退回 外编号 + 操作类型 + 操作时间。

文件菜单

  • 保存当前配置...：保存 iCloud 路径、书签权限和飞书配置。
  • 读取配置...：从之前导出的配置文件恢复当前环境。
